# GroceryPOS

نظام مكتبي عربي لإدارة البقالة، مبني باستخدام Windows Forms و.NET Framework 4.8 مع قاعدة بيانات SQL Server.

> **حالة المشروع:** قيد التطوير. الدخول وإدارة المستخدمين والأدوار والكتالوج والتصنيفات ووحدات البيع متاحة كبداية؛ وحدات المشتريات والمخزون التشغيلي ونقطة البيع لم تُنفّذ بعد. لا تستخدمه لتشغيل متجر فعلي قبل إكمال الاختبارات والمراجعة والنشر الآمن.

## الوظائف المنفذة

- إعداد حساب المالك الأول وتسجيل الدخول مع تجزئة كلمات المرور وقفل محاولات الدخول الفاشلة.
- إدارة المستخدمين وربط الحسابات بالأدوار، مع التحقق من الصلاحيات داخل الخدمات.
- إدارة الأدوار والأذونات وحماية أدوار النظام.
- تغيير كلمة المرور والتحقق من الحالية، وإعادة تعيينها إدارياً مع فرض التغيير عند الدخول التالي.
- البحث عن المنتجات وإضافة بياناتها الأساسية وتعديلها وتعطيلها.
- إدارة التصنيفات الهرمية ووحدات بيع المنتج والباركودات والأسعار.
- تسجيل أثر العمليات الحساسة في سجل التدقيق.

## المتطلبات

- Windows 10 أو أحدث.
- .NET Framework 4.8 Developer/Targeting Pack.
- Visual Studio 2022 أو .NET SDK/MSBuild متوافق.
- SQL Server 2019 أو أحدث.

لا يعتمد المشروع حالياً على حزم NuGet خارجية.

## الإعداد والبناء

1. افتح `GroceryPOS.sln` في Visual Studio، أو جهّز قاعدة تطوير جديدة باستخدام [`docs/GroceryPOS_Database.sql`](docs/GroceryPOS_Database.sql).
2. راجع اتصال قاعدة البيانات في [`GroceryPOS/App.config`](GroceryPOS/App.config). الإعداد الافتراضي يستخدم Windows Integrated Security إلى `localhost`.
3. ابنِ المشروع من PowerShell:

   ```powershell
   dotnet build .\GroceryPOS.sln --no-restore -p:GenerateResourceMSBuildArchitecture=x64
   dotnet build .\GroceryPOS.sln --no-restore --configuration Release -p:GenerateResourceMSBuildArchitecture=x64
   ```

4. شغّل `GroceryPOS\bin\Debug\GroceryPOS.exe`. عند أول تشغيل، أنشئ حساب المالك من شاشة الإعداد الأولي.

لا تشغّل سكربت SQL المرجعي على قاعدة بيانات موجودة؛ فهو سكربت إنشاء أولي وليس سكربت ترقية. خذ نسخة احتياطية قبل أي تغيير على بيانات فعلية.

## الأمان والبيانات

- لا تودع كلمات مرور أو مفاتيح أو ملفات قواعد بيانات فعلية أو نسخاً احتياطية في Git.
- استخدم قاعدة تطوير وبيانات اختبار معلّمة. لا توجد بيانات مستخدمين أو منتجات تشغيلية مطلوبة داخل هذا المستودع.
- إعداد الاتصال الحالي محلي للتطوير؛ اضبط حساب قاعدة البيانات والاتصال وفق سياسة النشر قبل استخدام جهاز آخر.
- ملف SQL يعرّف المخطط والبيانات الأولية، ولا يحتوي بيانات متجر حقيقية.
